# CF H5 V20｜手机优先玩法调研与最终方向（2026-10-18）

**产品决定：从 V19「自由走动的单人 FPS」转向「第一人称掩体换位突击」；保留真正的 3D 第一视角、手动瞄准、原生弹道、AI 伤害，删除自由跑图摇杆作为主操作。**

状态：**设计决策 / 待做 V20 可玩纵切片**，不是商业化发布许可，不是已经跑通的 V20 人体 A/B 实验。
V19（PR #64）是真实单人 PvE 的可运行技术基线，但原生 UX / 首杀验收尚未全绿，不能宣称正式可交付。

## 1. 方法和证据强度

- **外部资料核查**（官方游戏店铺、开发平台技术文档、独立游戏评测，2026-10-18 检查）：

  - 独立评测（自动移动、点击射击、松手回掩体/装弹、短时强反馈）: https://www.pocketgamer.com/major-mayhem-2/review/
  - Cover Fire / Google Play: https://play.google.com/store/apps/details?id=com.generagames.resistance （移动端简单操作、单人关卡，但其本身有多人/队伍相关内容；不能据此论证必须去掉队友）
  - 一条有代表性的用户反馈：抱怨触控瞄准和掩体切换控制限制：https://play.google.com/store/apps/details?id=com.generagames.resistance
  - Time Shooter 3: SWAT / CrazyGames: https://www.crazygames.com/game/time-shooter-3-swat （网页/手机可运行，但页面明确建议电脑体验）
  - Johnny Trigger 的用户反馈：简单射击爽快，过度重复也会失去乐趣：https://play.google.com/store/apps/details?id=com.time.trigger
  - Apple 针对触控游戏的建议：https://developer.apple.com/design/human-interface-guidelines/designing-for-games
  - CrazyGames H5 手机要求：https://docs.crazygames.com/requirements/technical/ （移动首页初始下载≤20MB；不是 TapTap 的通用门槛）
  - Google AdMob 激励广告自愿选择要求：https://support.google.com/admob/answer/7313578
- **我们自己真实的原生 Three.js QA 实验**：GitHub PR #64 https://github.com/23chen990/ai-mini-game-factory/pull/64
  - https://github.com/23chen990/ai-mini-game-factory/actions/runs/39049998579 真实原生 667×375 软件 WebGL 运行。
  - 记录到单人突击：1 玩家、0 友军 Bot、3 敌人 Bot；同一场连续触摸测试中，真实子弹累计曾为 12 发/2 命中/1 击杀，但角色也阵亡；自由看向、移动、开火、换弹、跳跃各动作都可以触发。
  - 开场与瞄准截图暴露问题：目标常在门洞深处，大小/对比度不足；手机 HUD 占屏明显。即便游戏物理能运行，免费小游戏首秒识别目标和瞄准成本仍高。
  - 原生首杀和多指验收历次出现 0 击杀、过早阵亡、脚本错误，不能声称自由跑图 FPS 的首轮体验已达到要求。
- **没有做过的实验**：没有 V20 半引导掩体玩法的完整可玩原型，也没有真人随机 A/B 试玩数据。下面是证据约束下的产品决定，不是伪造的转化率结论。

## 2. 三种方向对比与选择

| 方案 | 手机同时操作 | 玩家有意义的决策 | 短局 H5 适配 | 当前代码迁移 | 判定 |
| --- | --- | --- | --- | --- | --- |
| A 完整自由移动双摇杆 FPS | 左移动 + 右转视角 + 开火 + 换弹/跳跃；并发多 | 路线自由，但经常要先找到敌人 | 现有失败和模糊 HUD 风险高 | 最少 | **不继续作为默认玩法** |
| B 完全站桩点靶 / 单键自动过场 | 最低 | 缺少移动权，容易重复 | 高，但后期乏味 | 一般 | **不选** |
| C **第一人称掩体换位突击** | 右指瞄准 + 左指开火，非射击阶段点选左/右掩体 | 掩体、暴露时机、敌人次序、换弹窗口 | 高；单局可压到几十秒 | 保留原生射击/碰撞/AI/地图、替换移动交互 | **选定 V20** |

为什么不做传统 Cover Fire 复制品：我们坚持第一人称、真实几何 LOS、玩家主动选择何时换掩体；不能只把玩家固定在同一射击点。
为什么不做完整版 Major Mayhem：其自动移动和 2.5D 点击攻击不能简单宣称适合我们的第一人称枪械；我们只吸收「松手躲回掩体、短时强反馈」与短关结构。

## 3. V20 核心交互约定（一个默认模式，手机/桌面共用关卡）

**手机横屏：**
1. **右侧屏幕拖动 = 自由小幅瞄准**，无需独立方向转身按钮；瞄准范围以交战弧为中心，禁止战斗中自动追踪/锁头。
2. **左下按住「开火」 = 探身并发射原生子弹；松手 = 缩回遮挡并停止射击**。没有自动开火，也不需要玩家边控制摇杆边开火。
3. 左右两个清楚的**掩体换位点**出现时，点任意一边可沿真实碰撞合法路径在 0.5–1.0s 左右完成短距离转移（时间是设计起点，非测试成绩）。若 NavGrid 没有合法路径，禁止移动而不是穿墙/瞬移。
4. **自动装弹仅在弹夹耗尽后发生**（现有枪械换弹状态机）；最多一个轻量提示，不长期摆四五个按钮。特殊狙击镜可改为该关默认瞄准状态，不要新增独立复杂操作。
5. 可以看到敌人枪口/红色警示/短暂预备动作，再决定是继续暴露射击还是缩回/换掩体。子弹与掩体遮挡由真实世界射线决定；没有 UI 假伤害，也不能暗中修改敌人血量。
6. 桌面鼠标拖/移动准星和左键开火；点左右掩体点或对应按键换位。**不再维护简易/复杂两套移动模式。**

**敌人交战：**
- 开局敌人在原生无遮挡视线中，整体身形在手机屏幕上可辨认，而不是只看到远端门洞上的红色标签。
- 一局 2～3 段小高潮：正面敌人露头、攻击预告/需要躲避、第二个敌人绕侧方或迫使换位；每段加入一个新的决策而非单纯叠怪。
- 难度来自敌人射击窗口、真实掩体位置、换位时机和弹药管理；禁止血量倍增、神枪手 AI、凭空偷袭、没反应机会的秒杀。

## 4. 八关建议内容（保留 ID 和可兼容的旧存档）

| 关 | 主题 | 有意义的新操作 |
| --- | --- | --- |
| 01 直接交火 | 1 个可见守卫 | 学会瞄准 + 探身射击；首次击杀即过，预期 15–25s |
| 02 交叉火力 | 两名敌人先后出现 | 选射击次序、不要长时间暴露 |
| 03 侧翼包夹 | 一正面一侧翼 | 第一次主动切换左右掩体 |
| 04 危险投掷 | 可见投掷物警示 | 缩回或换位避开攻击 |
| 05 定点狙击 | 远近层次与短暂射击窗口 | 精准瞄准、等待清晰窗口 |
| 06 仓库推进 | 两到三处连续合法掩体 | 主动推进再清掉下一段敌人 |
| 07 撤离压制 | 出口受敌人争夺 | 在限时内夺出射击/换位窗口 |
| 08 小型头目 | 特征鲜明的防守者+少量增援 | 识别攻击预告、选角度、持续完成多阶段突击 |

**注意**：这是 V20 新的关卡脚本设计，**尚未在代码中实现**。目前仓库里的八关仍是 V19 的任务型自由行走射击。不要把建议表述成既有功能。

## 5. 纵切片交付、实测标准和停止条件

先把第一关、第三关各完整做一局，再把不同的战斗事件扩成八关。这是优先实现的**完整玩法纵切片**，不是让用户自己选择玩法方向。
- 首次进入可玩的 H5 战斗力争 10 秒内；覆盖低端 Android/真机 Safari 的实际测量后再立正式预算。CrazyGames 的 20MB 仅作为参考，不是当前平台的强制标准。
- 开局 2–3 秒出现真实可打目标；5 秒内新手能发出第一枪；首关真人中位数 15–25 秒为目标（都**不是已达成的数据**）。
- 采集首次准星停留、第一枪、第一命中、首杀、玩家死亡原因、主动换位率、免费重试率和自愿看广告率。8–12 名不熟悉游戏的真实手机玩家，覆盖 Safari/Chrome。
- 必过真机检查：移动时不穿墙、屏幕不会失控、切掩体时不能被两套输入重复控制、失去焦点/翻转/复活后松开所有手指。
- 成功评价：玩家能具体说出「我躲慢了 / 贪枪 / 位置选错了」，而不是「怎么转不过去 / 根本看不见谁打我」。
- 激励视频只能在真实失败、内容价值明确、用户自愿触发后出现；免费重试永远可用。无 SDK 验收、真实授权前不能统计盈利或公开发布。
- 原上游 3D 游戏的商业授权在 PR #64 尚未证实；若不能拿到足够权利，需要重写来源敏感的内容/资产，不应直接发 TapTap 商用。

## 6. 项目执行指令

**停止继续修 V19 双摇杆灵敏度、人数和无聊走米数**。以当前代码为真实枪械/AI/地图的技术素材，但不要再做八关清单式参数升级。下一开发任务是 V20 单人第一人称掩体换位操控 + 第 01、03 关可玩关卡纵切片 + 真机布局和真实 QA（用原生计数验证、不可注入数据）。保留 Draft，直到新玩法确实能够连续玩、真实打败敌人并重试。
