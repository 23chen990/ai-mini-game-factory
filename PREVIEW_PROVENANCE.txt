WHY THIS BRANCH EXISTS
  Phone playtesting of V10 needs every stage open without replaying the
  career. This branch keeps the SHA-verified V10 build byte-identical except
  for four surgical edits (see below). Racing physics, shortcut network, AI,
  items, stage definitions and all grading logic are untouched.

THE FOUR EDITS (verified: exactly one bundle line differs from base)
  1. stageUnlocked() now returns true unconditionally.
     -> all 16 stages selectable from the lobby on a fresh save.
  2. CAREER_KEY: 'h5-mobile:qq-speed:career:v1'
             -> 'h5-mobile:qq-speed:career:qa-unlocked-v1'
  3. FUEL_KEY:    'h5-mobile:qq-speed:fuel:v1'
             ->    'h5-mobile:qq-speed:fuel:qa-unlocked-v1'
     -> test progress and fuel never touch the production save slots, so
        official-version progress on the same device stays intact.
  4. RacingCareer constructor starts on stage index 0.
     -> without this, an all-unlocked career would resume on the LAST stage
        (the mainline findIndex fallback), which would drop testers straight
        into the final boss stage and recalibrate AI speeds.
