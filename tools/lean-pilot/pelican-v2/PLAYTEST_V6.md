# 鹈鹕海岸冒险 V6｜真人试玩与发布前门禁

状态：**待执行流程，而非已获得的玩家结果**。先招募 8–12 名不参与开发的测试者，每人至少自然玩三局。不要为了让玩家撞车、看广告而改变碰撞几何、自动发奖励或增加不可避免的危险。

## 三局观察（不得代操作或反复教学）

1. **第一局**：观察进入后的前 30 秒，能否自行理解转向、捕鱼、跳跃；记录首次操作疑惑。
2. **首次失败**：先保持沉默约 5 秒，看是否主动点免费重玩；再问「你觉得刚才为什么失败？下次怎么避免？」分别记录玩家解释和观察到的真实原因。
3. **第二局**：核对是否凭预判克服相同障碍，记录“知道怎么做但操作来不及”的实际路段和屏幕录制时间点。
4. **第三局**：记录第三局后是否愿意主动开第四局；如果玩家在有复活价值的位置失败，可询问「假设完整广告可用，你愿意看一次继续本局吗？」现阶段不能宣称广告已经可用或真实播放。
5. 经玩家明确同意，主动点击「下载试玩数据」并提供 `pelican-coast-playtest.json`。不收集姓名、设备指纹、广告 ID、账号标识。

## JSON 可以和不能说明的事情

- `counters.start/fail/retry` 是离线设备的累计事件，**不是**独立用户、留存率或真实广告指标。
- `lastEvents[].reason` 只对真正结束的失败 `fail` 写入，取值只能是 `vehicle`、`barrier`、`timeout`、`fish-short`、`gold-short`；旧 JSON 没有这个字段仍有效。
- `revive_opportunity` 是“规则判定有潜在复活价值”的次数，不能用作广告点击、曝光或付费意愿。
- 立刻免费重试的统计必须同时报告被观察到的实际失败人数；“三局后想继续”以真的玩满三局者为分母，保留玩家的原话。
