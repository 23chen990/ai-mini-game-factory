# Narrow offline pilot tools

These tools operate on one explicitly named run, not the legacy autonomous Agent chain.
Keep new runtime dependencies at zero. Existing Zod Agent boundaries and production gates
remain unchanged; this native JSON validation path does not certify or feed legacy stages.
Only add-only run initialization, fixed native tests, read-only reports, local preview and
explicit export are supported. No arbitrary shell, model call, REA, billing or deployment.
Never edit run metadata, frozen research/acceptance hashes or thresholds to force a pass.
Keep HTTP browser QA and offline DOM QA separate. Human and commercial evidence stay NOT_RUN
until actually collected and reviewed. Follow docs/lean-pilot/HANDOFF.md for next work.
