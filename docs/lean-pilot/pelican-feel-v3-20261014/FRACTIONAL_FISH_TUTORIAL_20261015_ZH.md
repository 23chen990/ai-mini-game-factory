# 鹈鹕 V3.2｜自由骑行首关捕鱼教学（实验性修复）

目标游戏：鹈鹕海岸冒险 H5，独立工厂工作区 `runs/pelican-coast-v2-20261014`，代码在 `tools/lean-pilot/pelican-v2/runtime`。基线 PR #16 Draft `435fab73`。

## ACTION_FEEL 诊断

用户的“三条轨道锁死”体感是真实主观反馈，不因工程绿灯关闭。现有自由转向已经没有三条吸附位置，但首关头三条鱼全在路面中线，静止不动就可多次抓到鱼。假设这会弱化玩家理解“可以停在道路任意位置”的机会。代码证据充分；真人主观根因仍待验证。

## 最小改动

- 第 1 条鱼（15m）继续在中线，保证首次奖励。
- 第 2 条鱼（31m）改为道路横向 +0.98m；第 3 条（47m）改为 +0.35m，均非任一绘制车道中心。附近危险、5 关目标、速度和障碍不动。
- 同一坐标函数用于真实物理捕鱼与 Three.js 视觉位置，雷达只表示大致区域，不将玩家或鱼吸回三道中心。
- 第一条真正捕到后提示可轻点右键或右拖；前方出现道间鱼时提供对应小提示。无伪造分数、广告、碰撞、三星或成就。
- 不引入新按钮、资产、运行依赖、额外后端或强制跳跃。

## 工程正反对照与停止条件

无输入：第一鱼实际收入，第二条偏右鱼不应凭空拿到。自由转向至 +0.98m 和回到 +0.35m：必须实际碰到第 2、3 条才可加分。保留原有五关可自然通关、三星跳障和 WebKit/Chromium 触摸验收，不用注入状态。

本次实验不能证明真人觉得更好玩。必须以新提交 CI 的源码/构建产物为准；无实体 iPhone/安卓、低端机发热与后台恢复、2 位未经指导真人、真实广告与商业权利核查：保持 NOT_RUN/BLOCKED。PR 保持 Draft，不合并、不部署、不发布。
