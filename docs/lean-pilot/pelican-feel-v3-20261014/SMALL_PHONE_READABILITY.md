# 320×568 竖屏可读性补强

根据独立 WebKit 五关运行截图，V3.3 原版左下角三星进度 `#co-mastery` 只有 10px，完成/未完成状态对比弱。

本次调整 `coast.css`：进度文字改为 12px 和稍高字重、更深的背景、更高的不透明度，保留同样五个小目标，未添加操作按钮。布局仍使用原有 `flex-wrap` 自适应窄屏。

在 `experience-qa.mjs` 新增 320×568 真实浏览器小屏检查（在第一关实玩/存档通过后）：确认菜单中的开始按钮在屏内、没有水平溢出，开始游戏后三个按钮尺寸达到触控区域要求、进度文本至少 12px、不覆盖操作按钮，并保存小屏菜单和实玩截图。测试仍依赖可信触屏，不修改鱼数、时间、存档。

这属于浏览器尺寸验收，不替代 iPhone/Android 原生网页安全区、实际人眼可读性与 GPU 性能验收。
