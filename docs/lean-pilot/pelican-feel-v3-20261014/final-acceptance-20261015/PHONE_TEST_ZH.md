# 手机试玩：最简步骤

本版来源：PR #16 的 `26e1e0c65894babf674710af256268be6009aed1`。完整构建身份见同目录 `artifact-import.json`。

1. 手机与这台 Mac 连接同一 Wi-Fi，Mac 保持开机、联网。用 iPhone Safari 或 Android Chrome 打开 **http://172.16.133.209:4328/game/index.html**。备用地址：`http://kkerdeMacBook-Pro.local:4328/game/index.html`。链接仅在本地服务运行和网络可互访时有效。
2. 点“出发”，先自由玩一局。轻点左右微调，按住左右或拖动路面连续转向；跳跃可点按钮或上滑。靠近鱼会自动捕获。想从零开始，可用新的无痕窗口；正式测存档请改用普通窗口，且始终使用同一个地址。
3. 连玩三局，试一次快速反向、跳跃配合转向；再暂停/继续、横屏/竖屏、切到别的 App 后回来、锁屏后回来、刷新。首轮无需先通完五关；愿意继续时再测后四关、三星挑战和约 10 分钟连续游玩。
4. 反馈只需：**设备型号 / 系统与浏览器版本 / 哪里不顺或看不懂 / 当时第几关及操作 / 是否愿意再玩**。出现问题时附截图或录屏；说明用的是本报告哪个版本。手机实测和主观体验由你完成，收到反馈后再做针对性修复。

当前状态：`PHYSICAL_DEVICE_TEST=NOT_RUN`；`PHONE_REACHABILITY_FROM_DEVICE=NOT_RUN`；`HUMAN_PLAYTEST=NOT_RUN`。桌面触摸自动化不能替代上述项目。

打不开时：先在 Mac 打开 `http://127.0.0.1:4328/game/index.html`。Mac 能打开而手机不能时，优先检查是否同一 Wi-Fi、访客网络/热点隔离或 VPN。不要为此关闭安全设置。IP 变化后，以 Mac Wi-Fi 当前 IP 替换地址。也可以下载同目录 `pelican-coast-h5-26e1e0c.zip`，解压后用任意静态 HTTP 服务提供其中的 `game/`。

需要重新启动本次服务器时，在本工作树根目录执行：

```sh
node tools/lean-pilot/pelican-v2/serve.mjs 4328
```

同一游戏使用 IP、`.local` 或 localhost 是不同站点，浏览器存档不会互通；无痕窗口关闭后可能丢失进度。此包不包含原生小游戏包或真实广告，广告未接入提示属于已知状态。

补充观察：若撞到行人进入晕眩，请留意当时取消拖动、恢复骑行后方向是否符合预期。现有晕眩规则会忽略转向，此状态的手感未获验收；正常取消通过不能代替它。
