# 《鹈鹕海岸冒险》V3.3 真浏览器手感修复说明

## 有证据的失败
- [GitHub Actions 运行 38535598198](https://github.com/23chen990/ai-mini-game-factory/actions/runs/38535598198)：WebKit 五关自然通关成功，但专项 jump-gold 在第一关 139m 碰撞 x140 路障；旧脚本等到剩余 0.4s 才点击，而且 Playwright 会对闪动中的按钮重试 30s。
- Chromium 在第二关 245.2m 撞上 x246 路障，之后控制按钮被结算浮层遮挡。软件渲染下一个 Playwright tap 可能耗掉数秒游戏时间。浏览器检查不能仅报告“测试超时”。

## 已做的修复
1. 路障进入约1.45秒预告后，允许提前按跳跃，保持同道则在距离路障约3m时执行真实起跳；换道取消，不允许自动跳车或凭空获得金鱼/跳障计数。
2. 触屏测试仍使用原生可信 Playwright touchscreen.tap；直接读取可见按钮坐标，绕过高亮动画的等待；游戏若已失败就直接报告失败原因。
3. 危险提前4s考虑，跳跃挑战提前约1.15s预按，并持续留在奖励鱼车道约2.6s。
4. 游戏内提前跳跃有可见确认，高亮速度从0.3s放缓为0.75s。
5. 新增5条回归测试：早按成功、换道取消、其他道不自动触发、重复输入不刷分、汽车仍致败；独立本地32/32运行通过，最新 GitHub CI 和真浏览器必须重新验证。

## 边界
这一轮是修复真实浏览器捕获到的输入窗口和测试可靠性，不是假装 iPhone 性能已通过；真实广告、后台锁屏、实体真机仍未验收。不能把 V2 旧 ZIP 当新版成果。
