# 鹈鹕海岸｜三星去伪压力和捕鱼连击目标（2026-10-15）

## 目标、复现、证据边界
- 游戏：鹈鹕海岸冒险 H5。独立目标工作区：`runs/pelican-coast-v2-20261014/workspace`，源目录 `tools/lean-pilot/pelican-v2/runtime/`，GitHub Draft PR #16。
- ACTION_FEEL / 玩法+存档的局部调整。已有 Chromium/WebKit 五关正常无碰撞自然完赛用时约 40、52.5、61.4、68.5、75 秒，速度固定不可主动加速。旧三星限时分别约 50.6、64.4、75.4、81.0、87.4 秒；与“无碰撞”一起要求时，倒计时门槛几乎自动成立，造成多条目标却没有更多操作取舍。
- 根因是规则与输入的关系，而不是 WebGL 缺陷。历史 CI 只证明旧版，不能替代本次规则更改的 QA。

## 最小玩法取舍
1. 保留所有关卡、速度、普通通关、一星/二星、实际结束倒计时、跳跃与危险；不加入加速键、第三方资产、广告或新后端。
2. **三星才要求“本局最高真实捕鱼连击”**，替换冗余的限时。连续目标按 `Math.ceil(goal.count * 0.2) + 2` 为五关 4/5/6/6/7。通过真实位置碰鱼增加 streak，漏鱼或碰撞重置当前连击，最高值在本局保留。与跳过真实路障、额外捕鱼、金鱼、零碰撞共同决定三星。绕开路障安全抵达的一二星路径必须保留。
3. 星级 HUD 的原“限时”槽位改为实时 `⚡最高连击/目标`，关卡卡片明确写连击目标。结算提示缺连击时准确说“连续抓到 N 条鱼”；完成后显示最佳连击纪录，留出可理解的重玩理由。
4. 旧 `version:2` localStorage 兼容：每关个人纪录增加 `streak`，缺少、非法数据默认 0；历史已经获得的星级绝不撤销，无法从旧捕鱼总量伪造历史连击。仅自然完赛的高分记录可写入。

## 验收与停止
- 规则正反例：缺真跳障/缺鱼/缺金鱼/未达连击不能假三星；仅速度相同的快速完成不产生奖励；失败局不刷新纪录；旧存档升级保持过往三星。纯逻辑实际输入必须有五关三星可达路径。
- Chrome/WebKit 实际重新构建当前 H5，正常触屏五关自然通关，另测真实跳障、实吃奖励鱼、第一关三星、连击 HUD 动态增长、刷新后纪录、窄屏无遮挡；必须全过并保留原始来源，不能跳过失败断言。
- 手机真机、无引导真人理解/愿意重玩、发热和 WebGL 恢复、正式广告、上线/商业权限独立保留 NOT_RUN/BLOCKED。PR 保持 Draft，不合并不发布。
