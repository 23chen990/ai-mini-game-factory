# 鹈鹕海岸冒险：第一关车流压力实验

**回应玩家反馈：车像不动、骑得过快、没有压力。不是发布候选验收，也不是“已经好玩”的结论。**

## 直接玩

本机已启动： [第一关试玩](http://localhost:4370/) 。这是独立端口，避免旧试玩进度把玩家直接带到未重做的后续关卡。

从仓库启动：

```sh
python3 -m http.server 4370 --bind 127.0.0.1 --directory docs/lean-pilot/pelican-v7-pressure-20261020/playtest
```

## 玩家实际会遇到的变化

- 第一关骑行基础速度 **7.5 → 6 m/s**，300 米约 **50 秒**，不靠继续加速制造难度。
- 车辆真正迎面驶来：汽车 **4.6 m/s**、货车 **3.8 m/s**，轮辐转动。车辆先亮方向灯和箭头，再连续并线；位置与碰撞用同一套运动。
- 并线是预先设计的，不追踪玩家、不暗改死亡率。看懂目标方向可以脱险，站在目标位置会真实撞车；汽车仍不能靠跳跃穿过。
- 保留自由转向、跳跃和按住展翅。跳跃准备距离及第一关空中鱼间距随较慢骑行调整，不降低碰撞要求。
- 真正擦身而过时，角色旁短暂出现脱险奖励并触发音效。开始按钮的真实手势启用声音，仍可静音；没有全屏闪光或阻断操作的顿帧。

**这轮只重做默认第一关。** 后四关和无尽模式没有完成同等程度的压力重构；不能据此称整款游戏已具备留存或广告吸引力。
