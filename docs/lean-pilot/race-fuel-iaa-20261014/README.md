## 产品决策（本轮已确定）

- 首发取消真人联机；保持原六车本地 AI。任何真人/AI 逐辆身份标签均不是这轮需求。
- 手机横屏 H5，仅左/右驾驶＋暂停；自动油门、智能漂移、出弯小喷、自动氮气和极简 HUD 是**仍待赛车 v2 完成**的工作，不能将本次油量 PR 当成已解决驾驶体验。
- 四条已有赛道优先复用，8 种挑战：完赛、排名、有效漂移、测速、加油站接力、雪地排名、末位淘汰、车神对决。后四种尚未实现。先解决自然完赛率。
- 参考《CSR Racing 2》历史油量循环：10 格上限；每次正式参赛 1 格；每 5 分钟恢复 1 格；可选择完整观看激励视频加 2 格。**数值是历史案例的产品假设，后续可配置和试玩校准，不声称 2026 CSR2 当前运营数值。**
- 不做体力商城、看广告提速、真钱付费道具、练习场系统、金币双倍奖励、签到、额外服务端、多人同步或付费改装。
- 广告入口仅在赛前与结算时的油量为 0~5 格时可见；新手第一局且未满 60 秒禁止展示；不强弹、不显示在比赛中、不影响普通比赛公平性。
- 广告仅 SDK 完整结束并收到 `isEnded === true` 后加油；取消、无填充、超时、异常、双击或重复发奖都不给。
- 当前平台权限 `PENDING` 且没有 H5 App ID/Space ID；**燃油扣费必须暂时关闭**，玩家可以不限油试玩，避免“等油量但无法看广告”的死循环。等生产配置真实验证后自动启用。

## 本 PR 已做的实现

- `fuel.mjs`：独立单一数据结构 `{version,amount,updatedAt,lastAdAt,lastAdId}`；补油/扣油、上限、离线恢复、时钟倒退、倒计时、广告幂等和平台就绪判断。
- `main.mjs`：只对 `qq-speed` 开启；`h5-mobile:qq-speed:fuel:v1` 稳定存档键（不含 run ID）；赛道加载及原生开赛成功后扣油，加载失败不扣；赛前检查油量，选关和结算显示燃油信息和可选广告入口；未获平台授权则不扣油。
- `style.css`：新 UI 只显示在赛车选关与结算，不侵占两个驾驶键区域。
- `tests/fuel.test.mjs`：Node 内核单测覆盖规则、消费、离线恢复、广告合法性及重载；开发容器中初始独立版 **11/11 PASS**，入仓版本请务必重新运行 `node --test templates/web-lite/h5-source-mobile-v1/tests/fuel.test.mjs` 验证。未经 CI 或真实浏览器验证前不可声称整包全部通过。
