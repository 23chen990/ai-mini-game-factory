## 已执行的工程命令

```sh
pnpm run pilot:pelican:test
pnpm lint

pnpm test
node tools/lean-pilot/pelican-v2/difficulty-audit.mjs

QA_ENGINE=webkit QA_DPR=1 node tools/lean-pilot/pelican-v2/v7-journey-qa.mjs
```

自然脚本只通过正常触摸、按住、公开 HUD 观察运行。`window.__coast.snapshot()` 只用于核对结果，不用于注入状态或选择隐蔽路线。底层触摸桥生成真实 `isTrusted` 输入；输入日志必须和游戏事件对应，不能只看终点。

- 本次原生鹈鹕测试：**232/232**；包括原始碰撞、转向、存档、广告真实性，以及新增展翅物理、15/30/60/120Hz、预算/松手、空中捕鱼、原鱼线/金鱼、无尽组合、警告分级、移动布局与关键输入派发。
- 全仓 lint、typecheck：已实际执行通过；最终提交前再次检查定向 ESLint。
- 全仓 `pnpm test` **未全绿**：974 passed / 1 failed；18 个失败文件中，17 个是 Vitest 误收 `node:test` 文件，另一个是未修改的 `unknown-waiver-binding` 时效/阻塞列表断言。保留原日志；没有越界修改共享 runner、其它游戏或安全许可检查。
- 桌面原生 GPU 的帧率来自真实 RAF 采样；**不能换算成手机性能**。CI 是 Linux 软件渲染功能环境：已有体验驱动按配置选择低画质/reduced-motion，但旧 `qa.mjs` 没有应用这两项环境变量，仍是默认画质；本次定向输入实验保留其原画质，不以降画质换取通过。各环境均不冒充真机。

## 前后对比方法

基线：PR #69 `aeb9638`，本地 attempt 1。改造后：同一授权源、同一第一关长度/速度、同一移动视口，在各自新浏览器里走正常输入。每组包括无操作、单向、盲跳、预判、三局熟练路线，并保存全程录像、截图、HUD 轨迹、可信输入、实际终局事件。

基线七局：无操作约4.56秒撞路障；只向左约6.84秒撞车；盲跳约4.56秒失败；预判路线40秒完成（59分）；熟练路线三局均40秒完成（66分，20鱼、5金鱼）。

本次最终选定的 Chromium dispatch-retest 与 WebKit after 各三局熟练路线，全部为23鱼、6金鱼、77分，其中2条真实空中鱼。**这些是脚本操作水平，不是新手/高手真人样本，也不是因果隔离的留存实验。** 修复了测试脚本在终局消失按钮上的等待竞争，因此前后 driver hash 不完全相同；截图/录屏和所有原轨迹保留，不能仅把分差全部归因于新技巧。

### 保留的失败与实验限制

- attempt 2：新展翅提示挡路；实际截图推动紧凑样式修正。
- attempt 4：雨关已到28鱼；WebKit第二关只16鱼。对比真实事件确认只差79米的鱼，提前转向反而漏掉它；移动这条已有鱼到安全准备线，保持17鱼门槛。
- attempt 5：五关 Chromium 原判定全部三星；折叠收藏展开后不可点，两个引擎均复现，单独修复展开分支。
- 最初无尽脚本409米撞车：它把所有红色倒计时当作禁止穿越，未走剩余两秒以上的双触摸出口。**只修改 QA 的公开预告决策**，未改游戏死亡、碰撞、速度或道路；保留相同构建失败轨迹，之后实际跑过550米并正常主动结算。
- attempt 6 第一份 Chromium 对比中，第五局无实际游戏输入，驱动读数出现长间隔，34米死亡；另两局熟练路线完成。它不能算作已执行的“熟练策略”，也不能抹成 PASS。第二份串行复测三局技巧都完成，但盲跳最后一次触摸落在死亡后的覆盖层，却被驱动记作游戏操作；严格断言因此失败。修正为核对真实控件收到的可信输入，晚到请求单列，第三份 `dispatch-retest` 全部通过；两份原始失败报告均保留。原因仅能定位为输入未实际发出，不能无证据声称手机或游戏没有时序风险。

## 最终自检，不替真人回答

- 前10秒：确实有真实捕鱼反馈和必须应对的第一处危险；“觉得有意思”未知。
- 技巧：短按/按住/松手产生不同真实飞行，斜向鱼线使用自由转向；不是更换成三车道锁定。
- 爽感：惊险、跳障、空中捕鱼和结算反馈可观察；主观爽感未知。
- 路段变化：有行人、车流、雨中准备/落地、夜间预告、四种无尽组合；是否足以长期保持新鲜未知。
- 技术进步：低输入与熟练脚本结果分离；不能冒称三局 AI 重放证明了真人学习。
- 难且公平：不是继续堆死亡；保留挑战压力，增加可选上限，正确输入可走通已测路线。不能宣称所有手机和所有无尽种子已自然试玩。
- 主动重试/愿看广告：**未知**。免费重试可用，真实广告未接入。这是交给真人试玩的版本，不是已证明留存或商业化的成品。

### 原有回归脚本的额外失败

- 碰撞脚本等待开场后，先读/打印证据才转向，Chromium因此先撞到左侧61m车辆，未抵达原中央车辆目标。修正调用顺序；单独 `early-dispatch` 重测已通过，未换成较早的车辆来冒充原分支。
- WebKit碰撞前置一关曾在约700秒墙钟后只有14秒游戏时间，达到原预算失败；原因未确证，不延长预算掩盖。独立 `early-dispatch` 复测通过，原失败另存。
- Chromium五关脚本的首鱼截图/渲染读取耗尽开场窗口，之后才点暂停已撞路障。改成先以真实暂停键冻结，再保存明确标为 paused 的首鱼证据；原五关、存档与结算断言保留，独立复测通过。
- V4财务回归仍等旧140m路障，却在新增35m路障先死。沿用既有正常触摸开场绕行，仍要求真正撞原 `l1-o1` 和 `l1-o6`，没有改成接受任意死亡；两端独立 `v7-route` 复测通过。
- lifecycle 的离线单HTML、画质/旋转尺寸、工程级context loss/recovery通过；**真实后台自动暂停未通过**。退出码0不等于报告通过。
