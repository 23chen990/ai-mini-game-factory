## 新开发路线

已有授权 H5 源码 → 原版可运行基线 → 手机触屏简化 → 三个短关卡 → 胜负/重试 → 一个激励视频广告位 → 真实手机测试 → TapTap H5 试玩审核 → 用真实数据决定是否继续。

优先鹈鹕、其次赛车、最后 FPS。三款都要有可用方案，但每次只将一款推进到发布级 QA，别让三款并行重做而全部半成品。参考源码已存在原生触屏支持，三个 build.mjs 会输出独立单 HTML；不需要 Unity、APK 或重写 Three.js。

## 游戏一：鹈鹕骑车（P0 第一款）

- 源码切入：pelican-bike/src/main.js 的 settings、S、updateRide、updateFishes、jump、frame；pelican-bike/index.template.html 的 .touch 布局与开场。
- 原样保留 3D 场景、骑车物理、抓鱼与跳跃；不用新建赛道或大批美术。
- 挑战模式禁用 settings.autopilot（原版4秒没主动变道后会自动追鱼，挂机可能过关），自由骑行仍可保留原样。
- 接入3个目标：90秒抓3条鱼；120秒抓5条并跳1次；150秒拿鱼分12。成功/失败/重开和任务可见进度必须对应真实 S 状态。
- 金鱼出现概率约12%，不要强制指定“必须抓到金鱼”才能过，否则关卡过度依赖随机数。
- 存档只保存过关进度、最好成绩、静音/画质。非必要相机/G​UI收进更多菜单；优先保留左右变道、跳跃与目标提示。
- 配置文件：examples/lean-pilot/h5-quickport/three-game-slices.json。该 JSON 为方案，不是已经连进游戏的可玩内容。

## 广告：实质上已经做好的最小可复用部分

- 浏览器兼容、无依赖、只负责安全发奖的模块：tools/lean-pilot/h5-rewarded-guard.mjs。
- 真实测试：tools/lean-pilot/tests/h5-rewarded-guard.test.mjs，可直接运行 node --test，已本地通过9项（正式 GitHub CI 结果另核）。
- 防止首次60秒或首关展示广告、关闭视频就发奖、广告加载失败卡住游戏、重复点击/重复领奖。grant 回调如出现不确定写入结果会阻止自动重发，需要实际游戏实现幂等存档。
- **不是 TapTap 的 H5 SDK**：由产品代码根据真实 H5 接口实现 show()，仅当平台确认视频完整播放后 resolve true；不可把展示成功或关闭回调误判为观看完成。
- 首版只要一个玩家自愿点击的“结算奖励加倍”入口即可，不要同步上复活、插屏、banner 或会员系统。没广告仍能完成游戏和正常重玩。
- H5 平台广告开通、主体/财务信息和正式广告位需要开发者账号确认。普通 Tap 小游戏的 tap.createRewardedVideoAd 示例不可直接套用到 H5。

## 工厂怎么反哺：只要最小三个能力

1. “现成授权源码直接改”入口：固定来源、保留原版构建、目标平台、最低修改点。可读源码优先直接修改，REA 不再是每款产品的必跑步骤。
2. “小目标关卡”使用每类游戏原有状态/事件组合出3个可见目标。三款保留不同实现；不创建三款通用引擎、代理系统或大量模板。
3. 一份可被三款移植的 IAA 发奖安全守卫 + 最少真实触屏/广告 QA。平台适配可换，但发奖纪律不变。

PR #7 的 research-to-build 研究门禁对反事实脚本目前严格要求 180 秒。我们的90~150秒短关卡**不能造假填180来骗过门禁**；PR #7 暂保持不变。Codex 如需集成，应增加明显的“已有源码直接改造”轻量分支，且不能放松原研究路径检查，不另建工厂。

REA 静态实验见 PR #8；后续如果研究不能影响游戏开发，先停止。已有源码不必再浪费时间完整逆向。

## 不要过度打磨：最小交付检查

- 使用自己控制的独立游戏仓库复制/派生已授权源码，保存原始 commit 与未修改构建，不能改原作者仓库。
- 安卓/iOS H5 手机实际开始、触屏、暂停/后台、目标结算、重开；模拟尺寸 390×844 和 844×390，再至少1台真实手机（真机未做就标待做）。
- 30秒内知道怎么操作；90~150秒有目标与结果；不操作不能挂机过关；不靠调试注入状态完成关卡。
- 广告四分支：完整观看、途中关闭、请求失败、重复点击；只完成才奖励，关闭或失败无广告也不阻断游戏。
- 不需要先上榜单、复杂经济、多种皮肤、后端、多玩家、50关。三关可玩就申请试玩测试。
- 在商业上线前确认作者许可范围、第三方商标/地图、美术等、小游戏前置备案、平台 H5 广告资格。

**停止条件**：授权 H5 关卡+手机可玩+基础广告测试达到要求即可 GO 试玩；因第三方 IP、TapTap 账号资格或 H5广告权限未解决而不能上线时标 PENDING/STOP，而不是无限重做产品。
