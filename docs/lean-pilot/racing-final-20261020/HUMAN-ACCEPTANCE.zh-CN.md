# 极速飞驰实机与玩家验收步骤

使用同一交付 ZIP、记录 SHA-256。不要调比赛时间、坐标、进度、成绩、油量或解锁状态；通过正常入口推进。保存有来源的真实通关存档可用于恢复已取得进度，不得用手写成绩替代。广告替身结果单独归类。

## 设备记录

至少一台 Android Chrome/TapTap H5、一台 iPhone Safari/TapTap H5。记录型号、OS、浏览器/WebView、分辨率、横屏 CSS 视口、刷新率、画质、渲染缓冲尺寸、网络、加载时间、10 分钟热机帧时间及峰值内存；录屏和截图使用原始文件。桌面 M1/触摸模拟/WebKit 不能填入这两行。

## 常规旅程与精确分支

1. 全新来源进入：默认免费车、最新未通过关、六车正常预览；未拥有车不能偷装备。分别看 667×375、844×390、刘海安全区和竖屏提示，检查 UI 遮车与按钮遮挡。
2. 连续正常驾驶第 1、4、7、10、13、22、30 关（只能通过合法通关/平台允许的真实广告解锁到达）。覆盖速度赛、道具赛、短赛程、近道、立体交叉与后段强度。每局记录路线选择、碰撞、名次变动、被超越、耗时和失败归因。
3. 左轮盘保持左转并漂移，紧急向右反打，再释放。观察车身方向和运动方向，不只看轮盘或 telemetry；不得继续向错误方向滑行直至撞墙。右手小喷、氮气、道具分别操作，并与左手连续触摸共存。
4. 真实获胜结算→下一关；真实落败→免费重玩；本机刷新/关闭重开恢复奖励与选车。尝试多个快速点击，不重复扣费/发奖。
5. 漂移中切后台/锁屏/来电后恢复、切横竖屏、暂停再继续，确认没有卡住的方向或动作，没有后台继续扣时间/播放广告，音频可恢复。
6. 真实激励视频分别完整观看、取消、无填充/失败；断网/恢复；视频期间后台再回来。只有有效完整回调和存储成功才获得一次奖励。平台无关联 ID 时，重点核查迟到的旧关闭事件不会记到新奖励。
7. 不看任何广告，使用基础车辆推进并失败重试；确认补给/等待是可理解的自愿路径，不以暗中作弊或不可恢复失败强迫广告。

## 判定

主观驾驶与压力需要不同熟练程度的真人样本。逐关记录实际结果，不把固定种子 AI 完赛率叫真人胜率。出现按钮混淆、反打失灵、无可见失败原因、无法重玩、保存/广告异常或低清晰度掩盖低性能，保持 BLOCKED。高关卡没有自然覆盖也必须保持未验收，不用调试通关补齐。
