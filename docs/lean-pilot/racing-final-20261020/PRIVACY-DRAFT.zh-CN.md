# 极速飞驰隐私说明草案

**状态：未发布；不构成可直接上线的最终政策。** 运营主体和用户联系渠道尚未确认；接入真实平台 SDK 后必须补充其准确版本、数据类型、目的、处理者、存储与删除方式，并完成平台要求的授权交互。

## 当前浏览器验收包

- 游戏在当前浏览器、当前网址的本地存储中保存：关卡解锁、星级、最佳成绩、车漆和赛车所有权、油量及补给时间、操作/画质设置；还保存有限的本机试玩统计，用于回合和重玩反馈。
- 当前游戏逻辑不提供账户、云存档、设备间迁移或跨网址共享。所谓永久解锁仅表示**此浏览器来源内持久保存**；清除网站数据、无痕会话结束或更换浏览器/设备可能丢失。页面暂停设置已说明边界。
- 本机试玩统计不主动上传到分析服务器。网页托管服务可能依法处理访问 IP、时间和服务器日志；其实际运营者与留存期限必须在最终政策中披露，不能据此宣称完全不处理任何数据。
- 当前验收包没有真实广告权限，广告替身只用于自动测试，不是用户广告服务。正式接入后不得沿用“未使用 SDK”的表述。
- 玩家可以在浏览器网站设置中删除本站数据。此操作会同时删除成绩与解锁；目前没有云端恢复能力。广告解锁必须在完整有效回调且本地写入成功后才确认获得。
- 当前浏览器包不请求定位、摄像头、麦克风或通讯录；背景音乐/音效由游戏音频代码生成。关闭/暂停音频并不要求额外设备权限。

## 发布前必须补全

运营主体的法定名称、联系渠道、政策生效日期；适用儿童/未成年人规则；平台/广告 SDK 清单和隐私链接；数据处理与保存期限；撤回同意、删除和申诉途径；真实部署域名及其托管日志说明。不得以“仅本地存档”替代 SDK 自身的数据披露。
