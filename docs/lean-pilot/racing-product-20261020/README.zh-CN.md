## 打开就能看到的改变

1. **手机跟车镜头独立调整**：缩短跟车距离，降低高速与氮气期间的过大广角。844×390 和 667×375 分别检查；不是将电脑镜头一起放大。电脑原生距离、视角与速度镜头公式不变。
2. **双端操作表达不同**：手机固定方向盘和右手按钮，氮气数量、道具图标、小喷就绪放在按钮内；电脑显示键盘状态条，不显示手机方向盘。电脑道具赛现在 Space 用已获得氮气、Ctrl 用道具，不再共用一个模糊动作。
3. **真实漂移/加速反馈更克制**：缩短尾焰，分别限制手机和电脑的粒子大小/透明度。特别修正实际电脑驾驶中白色漂移烟雾遮盖车辆的问题；不改变粒子事件、物理或奖励。
4. **首页和结算做减法**：首页保留选车、选关、车漆和开赛，简化重复规则；默认移除 QA 导出。结算突出本场名次、时间、真实目标差距和下一关/再来一局，统计及排名放到可展开详情。展示本场星级，不把历史三星冒充本次成功。
5. **奖励信息更明确**：预览赛车说明外观奖励和车型性能相同，不制造广告数值优势；本浏览器保存边界仍保留。结算加油完成通知不会因油量恢复而立刻隐藏。没有增加广告点或削减免费机会。

## 验证范围与边界

路线为 **formal-fixer**：沿用修复历史，先复现/定向测试，再改代码与实际浏览器复测。没有新增 Agent/Gate、生产依赖或后台。

本地源码回归、lint/typecheck、浏览器画面、正常输入和资源操作有记录；最终细目以发布附件为准。自然驾驶中的失败和旧布局 QA 采集器对新结算卡片的误判都保留。修正采集器后仍要求原生名次、真实时间、当前星级与存档一致，没有放宽通关门槛。

仍不是“真人已证明好玩、广告转化已证明”的结论。无真实 Android/iPhone、无正式平台包、无真实广告位验收；版权/平台阻塞沿用既有清单。状态为 **WEB_RC / 发布 BLOCKED**，不是 PLATFORM_RC 或 READY_TO_SUBMIT。

诊断导出仅在显式 `?qa=1` 入口显示；默认玩家入口不出现测试按钮。
