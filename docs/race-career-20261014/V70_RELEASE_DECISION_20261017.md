# 极速飞驰 V7.0｜短生命周期 IAA 试玩版交付与商业发布门槛

## 产品原则
这是一个手机横屏、短时游玩的 H5 竞速游戏，不是大型职业赛车手游。保留现有30条实体路线，但**不新增关卡练习模式、长线养成、每日强制签到、赛中教练或复杂任务面板**。第一场必须直接有对抗、连续转向和速度感，用户可能只玩1–3场。

## 本轮已实现（代码）
1. **操作反馈**：单轮盘、手动漂移/小喷/氮气/道具。借鉴已验证移动响应分支降低死区和全行程；小于单帧的真实漂移按键边沿可缓存到下一次原生物理步。松手、pointercancel、切后台均清理输入；不得自动反打或篡改赛车轨迹。
2. **性能与可读性**：昂贵 DOM 速度/道具/任务提示只以约30Hz刷新；输入、物理、AI、比赛结算仍使用原生步进。持续低FPS逐级降画质，短暂掉帧不贸然降低，手动画质偏好优先。
3. **公平失败→再次挑战**：保留V6.2的一次会话内同关免费重试（当油量系统生效），无SDK时无限免费试玩。未达成真实名次或技能目标不得假通关。
4. **短会话可选广告奖励**：仅在真实失败、游玩至少一局及会话60秒后，如果官方TapTap H5激励广告位真实可用，在结果页显示非主要按钮“看广告 · 下局额外氮气”。仅当视频完成回调 `isEnded === true` 才给**下次同关真实赛车库存加1瓶手动氮气**，不是接着当前比赛复活、不是净广告收入证明，也不提升AI/修改名次。取消、失败、延迟切关不发奖励；同一失败仅尝试一次，每会话最多2次尝试，至少90秒冷却。原免费重试优先、广告按钮次要、不能强制观看。
5. **道路**：继承 V6.2 的30条实际物理路线、10条可驾驶分叉与本机只读路线选择记录，不新增地图和画面指导层。

## 工程测试与限制
- 单元：轮盘回正、短漂移按键边沿、cancel、氮气与道具独立、输入/物理不降采样、持续低帧率画质、无SDK隐藏广告、真实失败才可广告、完成才奖励、跨关卡/晚回调/重复领取不得发放、不篡改进度。
- 集成：原生赛道/AI物理、实际打包 Chromium WebGL 手机触屏、7种横屏布局、真实第30关分叉、职业解锁与旧存档、正式构建SHA一致的隔离预览。
- **工程通过 != 玩家觉得好玩**：浏览器模拟不提供真实设备触屏延迟、自然通关率或广告观看意愿。以真实手机至少3场/人测试首场易懂、连续反打、触控丢失、失败是否愿意立刻重试；不以历史CI模拟当真人留存数据。
- 当前玩家行为摘要本地导出，不收集个人标识，不代表实收广告款。

## 商业上架独立阻断项
1. **资源和源码权利**：目前构建仍引用上游固定赛车工程快照。Three.js 的MIT许可不自动覆盖其它游戏源代码、视觉资源、原生关卡设计和音频；必须逐项核实商业使用权。即使修改文字和模型外观也不等于取得商业授权。
2. **TapTap平台账号与广告**：需要开发者认证、收款财务主体、正式广告开通及可用的广告位ID；普通浏览器缺官方 SDK 时不会展示广告。按[官方激励视频文档](https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/ad/rewarded-video-ad/)的 `isEnded` 判断只发放完整观看奖励。
3. **小游戏备案/提审与发行材料**：按[TapTap 小游戏前置备案](https://developer.taptap.cn/minigameapidoc/quick-start/guide/pre-filing/)准备材料，核实游戏所属类别与地区适用性、宣传视频、隐私与广告规范；不得假称商业上架完成。
4. **实体设备与真实业务**：Android/iOS 横屏 WebGL 和网络环境至少各一部实际试玩；广告完成→用户领取→真正下局使用氮气完整跑通，并从平台后台核验广告展示与结算数据。线上收入、留存和eCPM仍未知。

结论：只有同SHA CI及隔离预览全部成功后，标记 **CODE_READY_INTERNAL_PLAYTEST**；必须完成上述商业审核，才可以称为 **RELEASE_READY_COMMERCIAL**。PR维持 Draft，避免覆盖已验收的V6.2稳定试玩包。
