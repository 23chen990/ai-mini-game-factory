## 本轮已做（仅赛车源码）
1. 保留 V5.1 唯一轮盘 + 手动漂移/小喷/氮气/道具，不恢复旧双键，不在比赛 HUD 插入提示文案。保留 16 关物理线路与固定真实 AI 难度。
2. 正式燃油系统开启时，**每个关卡每次应用会话首次失败**奖励一次同关免费复赛。限当前关卡 ID（每日挑战与职业关分离）、不可累加、重试倒计时真正启动后才消耗，后续失败不再刷出免费票。它不是赛中复活，不能伪装成实际完成的激励视频。关闭平台广告/燃油时仍按原本不限油试玩。
3. 菜单/结算页右上角「导出数据 ↓」由玩家明确点击后下载本机 JSON；记录比赛开始、完赛、达标、失利原因、最多40局摘要、同关复赛、广告回调**信号**（不代表广告结算收入）。不会自动上传到服务器，也不包括姓名、设备 ID、浏览器指纹或用户号。
4. 浏览器 QA 从真实打包后的 WebGL 游戏启动，测试原生 Input.frame 接收同一时刻的右反打与漂移，并检测按钮位置。真人驾驶的转向体感/胜率仍需要实体手机确认。
5. CI 对 V5.x 自有功能分支触发，不再因未加入固定旧分支名单而跳过；只有赛车 CI 成功后，才将同一 SHA 打包文件推送到独立 `preview/racing-v53-core-loop-20261017`。构建与发布的来源 SHA 可由 `PREVIEW_PROVENANCE.txt` 核对。

## 真正决定继续投资的 20–30 人盲测
- 让不同水平的玩家用自己的手机连玩至少三局，再追加 05/11 关试验；不同人不需要被强制进入简单教学关。
- 每人分别记录设备/系统/浏览器（**由玩家自愿提供**）、试玩分支的 `SOURCE_COMMIT`、首局完成、首局目标成功、失败归因、是否自主重试、是否愿意第二天回来、是否自主愿意看激励广告。
- 使用各人**自愿导出的本机 JSON**配合口头/文字反馈。自动化测试生成的 JSON 不纳入真人样本统计。
- 初步实验目标（非行业事实或已达成绩）：首局完成率≥80%、首局达标率30%–60%、失败后自愿重开率≥50%、三局完成比例≥40%、失败公平认同≥75%。低于目标应先检验操作和目标设计，而不是继续提高 AI 数值。
