## 二、最重要的改变：只保留左右两个驾驶按钮

**默认手机操作只有左转和右转两个按钮。**

玩家不再需要主动按漂移、小喷、氮气、油门、刹车或换位。

操作规则：

- 按住左：向左转向。
- 按住右：向右转向。
- 松开：方向逐渐回正。
- 油门：比赛期间自动加速。
- 漂移：在合适的速度、转向持续时间和弯道条件下自动触发。
- 小喷：成功漂移结束、车身回正后自动触发。
- 氮气：集满后，在适合加速的时机自动使用。

**注意：简化的是操作，不是赛车的驾驶深度。**

我们应该继续保留漂移角度、抓地力、集气效率、完美小喷、氮气速度、碰撞减速等成熟机制。

玩家依然需要通过选择路线、把握转弯时机和松手时机取得更好的成绩。

### 自动漂移的具体要求

不能简单设定为“按住左或右超过某个时间就必然漂移”。

请结合现有物理、车速、转向状态和赛道曲率判断：

- 轻点方向时只正常转向。
- 符合条件的连续转弯自动进入漂移。
- 漂移开始要有明显甩尾、轮胎特效和声音。
- 持续合理转向时可以维持漂移。
- 松手或车身回正后结束漂移。
- 直道微调方向不能反复误触发漂移。
- 速度太低、碰撞失控或赛车尚未恢复时不得异常触发。

优先通过输入适配器驱动原来的 `shift` 和转向状态，不要另写第二套漂移物理。

### 自动小喷

原版已有约 0.5 秒的小喷窗口，其中前约 0.2 秒属于完美小喷。

手机双键模式下不要求玩家手动点击。

当一次有效漂移结束、满足触发条件时，自动执行现有小喷机制。

需要特别检查：

- 一次漂移只能按原规则触发合理次数的奖励。
- 不能在每帧重复触发小喷。
- 不得仅因为松开一个方向按钮就无限加速。
- 完美小喷应通过实际转向质量、漂移时机或车身恢复情况判定，而不是每次自动给予最大奖励。
- 保留明显的喷火、加速和声音反馈。

### 自动氮气

保持原版漂移集气和氮气容量。

集满以后可以自动使用，但应避免在碰墙、原地打转或明显不适合加速的时候浪费。

建议优先使用简单可靠的规则，例如：

- 赛车正常行驶；
- 不处于碰撞失控；
- 有可用氮气；
- 当前处于比较适合加速的路段或出弯阶段。

如精确预测道路曲率开发成本较高，就使用可靠的简化判断，不要研发复杂自动驾驶 AI。

允许在适当的测试中调整氮气积攒速度，让普通玩家也能经常感受到漂移和喷射的爽感，但不能让赛车一直处于无限加速状态。

## 三、彻底重新设计手机横屏 UI

我之前发送的 iPhone 试玩截图已经证明，目前界面非常拥挤。

主要问题：

- 顶部出现重复的信息栏。
- 六人完整排名占据左侧大片区域。
- 圈数、巨大计时器和集气面板占据屏幕中央。
- 小地图过大。
- 原版触屏按钮数量过多。
- 漂移、小喷、氮气、刹车和换位按钮同时遮住赛道。
- 完整 PC 端 HUD 与新增 H5 适配 HUD 相互叠加。
- 玩家开车时很难专注观察赛道与对手。

**不要在原版 UI 上继续叠加新 UI。请统一成一套真正为横屏手机设计的比赛界面。**

### 目标布局

顶部左侧：

- 当前名次，例如 3/6。
- 当前圈数，例如 1/2。

顶部中央：

- 紧凑的比赛时间。
- 不需要巨大的计时面板。

顶部右侧：

- 小型赛道地图。
- 暂停按钮。

底部：

- 左下角：大号左转按钮。
- 右下角：大号右转按钮。
- 中下方：细小的氮气/集气进度提示，可以在不遮挡赛道的情况下显示。

其余区域主要展示：

- 玩家赛车。
- 前方赛道。
- 其他车辆。
- 漂移、碰撞、加速和超车反馈。

### 必须删除或隐藏

正常竞速过程中不再显示：

- 漂移按钮。
- 小喷按钮。
- 氮气按钮。
- 油门按钮。
- 刹车按钮。
- 道具换位按钮。
- 完整六人排行榜。
- 巨型速度表。
- 多余的最佳单圈信息。
- 重复的 N₂O 图标。
- 原版 PC 键位说明。
- 无关的 GitHub、社交链接。
- 重复的暂停、计时和成绩栏。

必要的完整成绩、比赛统计、画质设置可以放到结算页面或暂停菜单。

**最终正常比赛画面中，除暂停外，玩家只有两个可以操作驾驶的按钮。**

### 横屏适配要求

- 优先适配 iPhone、安卓手机横屏。
- 正确处理刘海、安全区、圆角和底部系统区域。
- 左右按钮位置自然，适合双拇指。
- 按钮不能和小地图、HUD 重叠。
- 按钮半透明，但必须容易识别。
- 轻触、长按和快速左右切换均正常。
- 中央赛道和玩家赛车必须清楚可见。
- 旋转屏幕时暂停并提供合理提示。

请使用实际 iPhone 常见的横屏比例测试，不要只在桌面大屏上调整 CSS。

## 四、保留赛车爽感，但让反馈更明显

操作虽然简化，但玩家必须清楚感受到自己的技术带来不同结果。

### 普通转向

赛车正常转弯，操作及时、可预测。

### 自动漂移

车身甩尾、轮胎烟雾、音效和集气进度共同反馈。

### 完美出弯

可以显示短暂的“完美漂移”或“完美小喷”字样，伴随明显加速效果。

### 自动氮气

短暂出现“氮气加速”提示、火焰和速度变化。

### 超车

可以显示简单的“超车 +1”或排名变化反馈。

这些提示必须短而清晰，不能长时间挡住赛道。

不要堆大量粒子特效导致手机掉帧。

## 五、画质与镜头

PR #10 目前默认使用低画质，原版其实已有 `low / mid / high` 档位。

请检查真实渲染质量，并在手机性能允许的情况下适度提升清晰度。

优先改善：

- 道路纹理和边缘清晰度。
- 玩家赛车及其他车的辨识度。
- 弯道和赛道边界。
- 抗锯齿及像素比例。
- 光照与合理的阴影。
- UI 字体清晰度。

根据性能采用合适的动态画质或简洁的画质档位。

镜头方面：

- 保留稳定的后方跟随驾驶镜头。
- 减少不必要的随机抖动。
- 漂移时仍可以表现车身侧滑。
- 氮气加速时保留适当的速度感。
- 避免 FOV 变化过大导致弯道看不清。
- 优先保证玩家可以提前判断转弯路线。

不要为这轮 UI 改造重新制作场景、车辆模型或大量美术。

## 六、第一局体验

我们的目标用户不一定玩过复杂赛车游戏。

请让用户在几秒钟内理解玩法。

进入游戏后只需要：

1. 选择一个默认赛道或直接进入第一场比赛。
2. 简洁展示“按住左右转弯，漂移和加速自动触发”。
3. 倒计时开始。
4. 玩家仅通过左右按钮完成比赛。
5. 结算显示名次、成绩，并提供“再来一次”和“下一场”。

首次引导应该短小，不需要玩家先阅读长篇操作说明。

第一场建议使用容易完成的赛道和适当的 AI 难度。

但不要让游戏自动帮玩家转向，否则会失去驾驶乐趣。

## 七、暂时不要扩展复杂游戏系统

这次的第一优先级是操作和 UI。

现有四张赛道、AI 赛车和比赛规则尽量保留。

暂时不做：

- 新赛车物理引擎。
- 新赛道生成器。
- 多人联网。
- 大型养成系统。
- 复杂商城。
- 大量新皮肤。
- 新的 Agent 工作流。
- 大规模 REA 逆向研究。

等双键赛车真正好玩后，可以利用现有赛道增加几个轻量赛事挑战。

例如：获得前三名、第一次拿冠军、在更难赛道上夺冠。

但不能让关卡设计拖慢这次手机操作优化。

## 九、必须真正测试

不要只用静态截图或单元测试证明成功。

至少验证：

1. 玩家只使用左/右按钮，确实可以完成比赛。
2. 普通微调方向不会误触发漂移。
3. 连续合理转向能够触发自动漂移。
4. 漂移结束能够正常自动小喷。
5. 集满氮气后能自动使用。
6. 不会反复自动小喷或无限氮气。
7. 左右快速切换没有异常转向。
8. 单手、双手触控都能正常操作。
9. 后台恢复和暂停不会产生卡键。
10. HUD 不遮挡赛车、道路和重要弯道。
11. 真实比赛能够正常排名、结算、重开。
12. 手机横屏画质和帧率可以接受。
13. 保留原版 AI 对手与物理机制，不产生明显退化。

必须使用正常模拟触屏输入运行完整比赛。

可以通过自动化测试辅助判断，但不允许直接修改赛车位置或强行设置胜利状态冒充完赛。

对于浏览器自动化无法验证的真实操作手感，应明确说明待真人验收。

建议保存旧版和新版相同场景的画面对比证据。
