## 发现与实际处理

| `COMPLETED` 被映射成候选就绪；路由遗漏体验合同/真人门禁 | 预览冒充商业完成 | `PREVIEW_ACCEPTED`；NEW_GAME 复用 canonical pipeline plan；新增五维只读 readiness 投影，而非另一套 QA |

| 隐式两次修复上限与文档五次上限矛盾 | 有依据也停；无依据可能重复烧钱 | 移除隐式轮数帽；保留显式预算。持久化每次 QA、证据副本、线程、输入/输出 hash、原子计数。相同故障不因截图名、时间或测量噪声变化而获准重试 |

## 保留、合并、移除、新增

- **保留**：既有 Zod 协议、母模板、运行时/平台适配器、Builder/Fixer 线程、双轨 Playwright QA、独立感知/参考比对、证据账本、权限/模型/成本控制、IAA、素材审批、不可变发行候选与反馈经验沉淀。
- **合并职责**：采集只产事实；Research 一次产拟定机制和既有五维行为/失败压力合同。新入口不增加一组泛竞品/创意 Agent，不再重做同一份研究。
- **移出默认路径**：创意发散、三原型赛马、先扩大量关卡；旧实验入口只保留兼容和回归。删的是默认负担，不是用得上的能力。
- **新增**：brief-only intake、URL 采集入口、缓存/审批绑定、截图序列重建、五维 readiness、保守修复 admission 和可重复第一方参考演示。没有新生产依赖、数据库、队列或服务。

## 当前统一流程

1. 提交来源简述；文件立即进入本 run incoming。身份未核验的 PENDING/未知/不匹配材料不用于机制结论。
2. URL 采集或视频抽帧；只记录可观察事实。跨域资源需显式公共域名白名单；身份检查仍独立。
3. 单次 Research 返回原有行为/压力/事件合同和拟定机制，观察、推断、未知分离。输入与提示不变则复用缓存；BLOCKED 不自动重花钱。
4. 人确认机制方向；审批绑定 inputHash 和草案字节。然后复用原来的 Blueprint/Builder，只先做一个核心切片。
5. 自动工程 QA + 新浏览器自然旅程；独立参考/感知比对；真人确认触控、压力、公平和重玩。任何一项缺失都不由 Builder 自评代替。
6. QA 明确失败才进入正式 FIX → build → QA。没有新的故障依据、未改变构建、中断未恢复或预算不足，记录原因后停。
7. 显式完整验证才展开正式美术、内容、IAA、商业预检、冻结候选及各平台包。逐平台真机/SDK验证和最终发行授权独立于 H5。

## 证据如何读取

- `pnpm verify`：共享工厂 lint、类型、单元/集成/浏览器回归；精确结果见同目录 `verification.json`。
- `pnpm factory eval`：既有工厂策略回归，不能替代浏览器或真人体验。
- `pnpm factory demo-reference --prepare`，再运行返回的 `fixture-run-id`：得到可玩自包含 H5、构建测试、自然输入截图及 `reference-demo-report.json`。
- `pnpm factory readiness <run-id>`：五维逐项返回证据、缺口和动作；不会把一个状态枚举当成全部完成。

### 第一方演示的诚实边界

Mooncut Trial 仅是本仓库明确自有需求的集成 fixture，**不是用户正在做的 Slice Master 项目**。它用确定性解释器而非 LLM读取明文需求，调用真实模板构建/测试和 Playwright。确认切割、落块、危险碰撞、重试、通关、重玩；再次 resume 不重复构建或研究。报告显式标注 `llmExecuted:false`、`humanAccepted:false`、`commercialReleaseReady:false`。

对 390×844 截图的人工检查能看到失败归因和重玩入口，但场景只占屏幕上部，终局按钮覆盖场景；这些是待产品评审的问题，不是本次给自己签发的感知通过。真实手指手感、压力曲线、长线关卡变化和重玩意愿尚未验证。演示不生成真人接受工件，也不越过独立参考门禁。

### Slice Master 的实际兼容性检查

已有证据清单区分了可用材料、缺失录屏和不相关录屏；未按文件时间替换任何缺失来源。只针对用户给出的页面作隔离网络采集，草稿和网络结果留在这个既有 run 的 incoming，**没有因为网页标题匹配就晋升为玩法证据**。页面文字可确认参考身份和描述，但不能测量手感、物理或难度。本次没有重跑其游戏构建或关闭旧 QA/FIX 问题。

- 新发现入口只支持 `idle-shop-v1`、`cut-stack-dodge-v1`；不是任意 H5 自动逆向器。旧空间/3D模板仍保留，但既有 Three.js Slice Master 不会被降级为新 2D fixture。
