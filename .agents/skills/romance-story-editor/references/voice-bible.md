# 人物声线档案与角色记忆审校

每位人物用以下最小表，先由已确认作品材料提取，不从性别、年龄或“高冷/甜妹”标签推断：

| 字段 | 核查要点 |
|---|---|
| 在意什么 | 当下具体目标与最怕失去的东西；事业不是恋爱的筹码 |
| 首选动作 | 遇到危机会先确认事实、安慰、提问、观察、谈条件还是冒险 |
| 表达节奏 | 长短句/反问/停顿/是否会先讲结论；要有可观察例句 |
| 沟通避区 | 哪些话题会回避，为什么；隐瞒不能等于撒谎万能特权 |
| 情绪泄露 | 用动作与语序体现紧张、嫉妒、关心，而非每人都“唇角微扬” |
| 已知事实 | 消息来源、时间、证据；听说不等于亲眼看见 |
| 关系阶段 | 初识/熟悉/互相吸引/约会/交往/冲突/暂缓/分开/朋友 |
| 主动性 | 在玩家没选她的情况下仍会做的事与面对玩家拒绝的反应 |
| 前后示例 | 只摘少量合法授权的角色原句，对照同一刺激下的差别 |

## 区分四种容易错的写法

- **同声化**：所有人都说“你让我重新认识你”，只是换称谓；应改为角色关注的具体事实与行动，而非换一种形容词。
- **机械口头禅**：每句话都俏皮/冷淡/讽刺/温柔；应随着场景和关系改变反应。坚定的人也会慌，活泼的人也会沉默。
- **假慢热**：对外说“还不确定”，实际剧情已把女主当恋人、自动增加亲密；必须看对白、行为和引擎状态三者是否一致。
- **作者借人物讲话**：人物解释剧情道德观或连说四句哲理，不推进眼前冲突；改成她在当前条件下真正想要解决的一件事。

## 对话的三条问题

1. 这个人知道这件事的**依据**是什么？
2. 他/她为什么**现在**要说，而不是以后或不说？
3. 听者接下来有什么可看见的行动或关系变化？

无足够依据就标为待定，别替角色编一个事后解释。
