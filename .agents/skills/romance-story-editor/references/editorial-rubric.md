# 中文互动对白审校量规（人工判断，不合成伪客观总分）

| 维度 | 判为问题的证据 | 改进方向 |
|---|---|---|
| 语义可理解 | 玩家不知主语是谁、代词指谁、为何突然翻脸 | 还原动作/信息顺序，减少必须靠作者旁注理解的暗示 |
| 自然度 | 完整演讲式句子、舞台腔、人物互相替读者解释设定 | 打断、具体小动作、日常反应，保留人物应有专业口吻 |
| 角色辨识 | 互换人物名字仍几乎成立 | 根据角色关切、专业能力、说话习惯和当前情感强度重写 |
| 情绪进展 | 初见救场就亲密、被拒绝后无成本直接续恋 | 保留理解/好感/信任/知情同意的独立台阶 |
| 玩家自主 | 选项是假选择，选择后实际行动不符标题 | 标签预告行动，分支即时反馈并让后文有差异 |
| 因果连续 | 人物知道未知秘密、用了不存在的道具、话题跳跃 | 查证可达前缀、实物、时间、人物知识图 |
| 非玩家能动性 | 原著男主或女主只为配合玩家而突然降智/失业 | 给每人对当前事实的合理判断和独立结果 |
| 可读手机排版 | 一屏多轮长篇抽象解释，重要选项不可见 | 分段、控制信息密度，关键动作靠正文可见 |

## 常见模板腔预警（不是自动删词表）

“从来都不是……而是……”“我终于明白……”“或许我该重新认识你”“你让我看到了不一样的世界”“这一刻命运的齿轮开始转动”。只有当它遮住眼前事实、重复表达或四个人无差别使用时才改。人物有意模仿文学腔可保留，但需上下文证明。

## 反例：改得更顺却变差

坏改法：“谢谢你救我，我好像喜欢上你了。”→“你真靠谱，以后都靠你啦。” 只是换了表面口气，仍强行建立关系。好方向：先让她核对危机确实解除、提出自己的后续计划，再因玩家独特行动留下一个具体可继续的疑问。必须与正式稿设定、当前路径一致，不能把这里的示意当剧情事实。

## 审稿结果写法

每个场景记录 `KEEP / REWRITE / LOGIC_REQUIRED / NEEDS_EVIDENCE`，附逐句理由、文本路径与可达前缀；不以模型打分宣称留存提升。关键玩家时刻可让真人复述“我发生了什么、我能选什么、我为什么还想见这个人”，记录实际反馈。
